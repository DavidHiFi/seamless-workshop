# Contributing to Seamless Workshop

Thanks for helping. Bug reports, ideas and pull requests are all welcome.

## Reporting a bug

[Open an issue](https://github.com/DavidHiFi/seamless-workshop/issues/new) and include:

- what you did, what you expected and what happened instead
- your Windows version, your Windhawk version and the Seamless Workshop version
- a screenshot of the Workshop window, and the error text if the PowerShell installer stopped

## Suggesting a feature

Open an issue that describes what you want to do and why. A screenshot or a mock-up helps.
To ask for a change to one of the mods themselves, open the issue on [davids-windhawk-mods](https://github.com/DavidHiFi/davids-windhawk-mods/issues/new) instead.

## Sending a pull request

1. Fork the repo and create a branch from `main`.
2. For the installer, edit `Install-SeamlessWorkshop.ps1` and run it on a machine with the Windhawk 2.0 alpha.
3. Check that the script still parses in Windows PowerShell 5.1 and PowerShell 7.
4. Keep each pull request to one change, and say in the description how you tested it.

`feed.json` is generated by the publisher each time a mod is published. Do not edit it by hand.
